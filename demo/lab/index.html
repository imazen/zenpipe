    What this page does and does not show

    MODEL backend. Tasks run the deterministic in-page model over the generated fixture. That qualifies orchestration — state transitions, admission, cancellation, reservations, stale-output rejection — and nothing else. It is not codec, memory or native-WASM qualification; unsupported media kinds refuse instead of faking success. Byte reservations are declared accounting — not measured peaks and not proven bounds. Cancellation here is async and cooperative between scheduled steps; no postMessage message can interrupt synchronous WASM, and nothing on this page claims otherwise. Teardown reports any task without a terminal receipt as unresolved, with its held reservation.
